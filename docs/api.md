# API Reference

Full interactive/browsable docs are auto-generated by FastAPI at
`/api/v1/docs` (Swagger UI) and `/api/v1/redoc` whenever the server is
running — that's the authoritative, always-up-to-date reference. This file
is a quick-scan summary.

Base path: `/api/v1`. All endpoints except `/auth/login`, `/auth/refresh`,
and `/health` (which is at the app root, not under `/api/v1`) require a
`Authorization: Bearer <access_token>` header.

## Auth
| Method | Path | Role |
|---|---|---|
| POST | `/auth/login` | none |
| POST | `/auth/refresh` | none (valid refresh token) |
| GET | `/auth/me` | any authenticated |

## Workers
| Method | Path | Role |
|---|---|---|
| POST | `/workers` | ADMIN, STOREKEEPER |
| GET | `/workers/search?site_id=&q=` | ADMIN, MANAGER, STOREKEEPER |
| GET | `/workers/{id}` | ADMIN, MANAGER, STOREKEEPER |
| PATCH | `/workers/{id}` | ADMIN, STOREKEEPER |

`national_id_masked` is the only form of the National ID ever returned by
the API — the full value is never exposed once stored.

## Transactions
| Method | Path | Role |
|---|---|---|
| POST | `/transactions/issue` | ADMIN, STOREKEEPER |
| POST | `/transactions/return` | ADMIN, STOREKEEPER |
| GET | `/transactions/outstanding?site_id=&worker_id=` | ADMIN, MANAGER, STOREKEEPER |

`issue` and `return` both accept a list of line items in a single request —
issuing or returning several tools in one store visit produces one
`Transaction` record per line, each with its own timestamp.

## Error format

```json
{ "detail": "Only 2 Safety Belts are currently available." }
```

Validation errors (422):

```json
{ "detail": "Invalid request data.", "errors": [ { "loc": [...], "msg": "..." } ] }
```
